# 국가 전쟁 플러그인 v2.0 (Nation War Plugin)

마인크래프트 서버용 **국가 시스템**과 **신상 점령 전쟁** 플러그인입니다.

## 🎮 주요 기능

### ✅ 수정된 사항
- **신상 공격 버그 수정**: 이제 왼클릭으로 신상을 제대로 때릴 수 있습니다!
- **국가 시스템 추가**: 국가를 만들고 멤버를 관리할 수 있습니다
- **국가별 포인트 시스템**: 신상 점령 시 국가 포인트 획득
- **자동 소유권 관리**: 신상 점령 시 자동으로 국가 소유로 등록

### 🏛️ 국가 시스템
- 국가 생성/삭제
- 멤버 초대 및 관리
- 리더/임원 시스템
- 국가 색상 설정
- 국가 포인트 시스템
- 소유 신상 추적

### ⚔️ 신상 전쟁
- 정육면체 형태의 신상 생성
- **왼클릭으로 신상 공격**
- 실시간 체력 표시
- 국가별 점령 시스템
- 자기 국가 신상은 공격 불가

## 📖 사용 가이드

### 1단계: 국가 만들기
```
/nation create <국가명>
```
예시: `/nation create 대한민국`

### 2단계: 멤버 초대하기
```
/nation invite <플레이어>
```
상대방은 `/nation join <국가명>`으로 가입

### 3단계: 신상 생성 (관리자)
```
/core create <신상이름>
```
현재 서있는 위치에 신상 생성

### 4단계: 전쟁 시작 (관리자)
```
/core start
```
이제 신상을 공격할 수 있습니다!

### 5단계: 신상 공격하기
- 신상 블록을 **왼클릭**으로 공격
- 체력이 0이 되면 점령 성공!
- 자기 국가 신상은 공격 불가

## 🎯 명령어 전체 목록

### 국가 명령어 (`/nation` 또는 `/n`)

| 명령어 | 설명 | 권한 |
|--------|------|------|
| `/nation create <이름>` | 국가 생성 | 모든 플레이어 |
| `/nation delete` | 국가 해체 | 리더만 |
| `/nation invite <플레이어>` | 멤버 초대 | 리더/임원 |
| `/nation join <국가명>` | 국가 가입 | 모든 플레이어 |
| `/nation leave` | 국가 탈퇴 | 멤버 |
| `/nation kick <플레이어>` | 멤버 추방 | 리더/임원 |
| `/nation info [국가명]` | 국가 정보 확인 | 모든 플레이어 |
| `/nation list` | 국가 목록 보기 | 모든 플레이어 |
| `/nation officer add <플레이어>` | 임원 임명 | 리더만 |
| `/nation officer remove <플레이어>` | 임원 해제 | 리더만 |
| `/nation color <색상>` | 국가 색상 변경 | 리더만 |

**사용 가능한 색상**: RED, BLUE, GREEN, YELLOW, PURPLE, AQUA, WHITE, GRAY

### 신상 명령어 (`/core`) - 관리자 전용

| 명령어 | 설명 |
|--------|------|
| `/core create <이름>` | 신상 생성 |
| `/core remove <이름>` | 신상 제거 |
| `/core list` | 신상 목록 |
| `/core start` | 전쟁 시작 |
| `/core stop` | 전쟁 종료 |
| `/core info <이름>` | 신상 정보 |

## 🔧 빌드 방법

### Windows CMD
```cmd
cd NationWarPlugin
gradlew build
```

### Linux / Mac
```bash
cd NationWarPlugin
./gradlew build
```

빌드된 파일: `build/libs/NationWarPlugin-1.0.jar`

## ❓ 자주 묻는 질문 (FAQ)

**Q: 신상을 때려도 데미지가 안 들어가요!**
A: 전쟁이 시작되었나요? `/core start` 명령어로 전쟁을 시작해야 합니다.

**Q: 블록이 부서지지 않고 데미지만 들어가요**
A: 정상입니다! 신상은 체력 시스템이라 블록을 직접 부수는 게 아닙니다.

**Q: 국가 없이도 신상을 점령할 수 있나요?**
A: 네! 무소속으로도 점령 가능하지만, 국가 포인트는 받지 못합니다.
